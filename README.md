# 엠버 슬라이드

판 전체를 밀어 동류항을 모으는 12라운드 퍼즐. 문자끼리·수끼리 더하고 합이 0인 짝으로 길을 엽니다.

## 실행
Node.js 22 이상, 추가 패키지 없음. npm start (4174), npm test, npm run build.

## Vercel
이 비공개 저장소를 Import. Framework Other, Build npm run build, Output dist. vercel.json 포함. 배포 전까지 ready_for_vercel로 관리합니다.

## 학습 확인
assessment/는 정수 계수의 동류항과 일차식 덧셈·뺄셈 표본을 독립 확인합니다. 승리로 공식 이수를 판정하지 않습니다. 학습 기록은 기기에만 저장하며 새 학습자, 설명과 교사 검토, JSON 내보내기를 제공합니다. 원문 PDF·추출문은 포함하지 않습니다.

## 참고와 검증
2048의 판 전체 이동 규칙을 수학적으로 변형했습니다. 코드와 그래픽은 별도로 제작했으며 원작 코드·미술을 복사하지 않았습니다. 공식 출처, 후보 비교, 단계별 판단과 반례는 design.json. 자동 테스트와 실제 브라우저 증거는 evidence/. 학생 대상 재미·학습 효과 검증은 아직 하지 않았습니다.
